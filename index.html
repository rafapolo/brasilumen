Como foi feito

Os pontos vêm do cadastro de CNPJ da Receita Federal: só estabelecimentos com situação ativa. Cada endereço foi casado exatamente com um endereço do Cadastro Nacional de Endereços para Fins Estatísticos (CNEFE) do Censo IBGE 2022, que tem coordenadas.

Não há recurso ao centroide do CEP: quando o endereço não casa, o estabelecimento fica fora do mapa. Por isso cada estado mostra quantos dos seus ativos foram geolocalizados. Vários estabelecimentos no mesmo endereço viram um ponto só.

A vista do Brasil é uma amostra de 2 milhões dos pontos dos estados, para caber no navegador. Abra um estado para ver todos os pontos dele. O Distrito Federal ainda não tem arquivo.

A soma de luz é aditiva: onde muitos pontos se empilham, a cor satura até o branco. Brilho controla quantos pontos são precisos para isso.

Dados: Receita Federal (CNPJ), IBGE (CNEFE, Censo 2022), via Base dos Dados. Mapa: MapLibre e WebGL. Código.
